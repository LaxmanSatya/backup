# pseudo code

'''
Write pseudocode by breaking your program's logic 

*into plain, 
*step-by-step English sentences 

without worrying about strict programming syntax
'''

**UnderStand  the GOAL First**

 Figure out what problem you need to solve or what the program should do.

**Break it Down**

Split the task into tiny, logical actions (like getting input, calculating, and showing output).

**USE UPPER CASE KEYWORDS**

Write control words like IF, THEN, ELSE, WHILE, FOR, and OUTPUT in capital letters to stand out.

**APPLY INDENTATIONS**

Indent lines inside loops or conditions to show structure and make it easy to read.

Example,

START
OUTPUT "Please enter your name: "
INPUT userName
IF length of userName > 0 THEN
    OUTPUT "Hello, " + userName
ELSE
    OUTPUT "You did not enter a name."
END IF
END
